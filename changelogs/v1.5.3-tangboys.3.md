# v1.5.3-tangboys.3 — 2026-10-04

本分支的首次公开预发布，汇总 Windows 后台守护、Codex 插件起停、多语言命令及中文工具输出修复。
基于 [chenhg5/cc-connect](https://github.com/chenhg5/cc-connect) 的 `dfad1941` 主线快照，版本号属于 tangboys 分支。

## 更新内容

- **源码安装兼容性**：从 PATH 中选择第一个 Go 命令，修复构建机安装多个 Go 版本时路径被拼接、安装失败的问题；新增先复现失败再通过修复的回归测试。

- **Windows UTF-8 工具输出**：新增 PowerShell 包装程序，在启动前设置 UTF-8 控制台代码页，修复中文路径和目录名乱码。自动查找真实 PowerShell，保留命令退出码与标准输入/输出/错误，沿用 Codex 沙箱。
- **Codex 插件起停**：插件 MCP 连接建立时启动 cc-connect，Codex 桌面窗口关闭后停止机器人后台及其 Agent 进程。多个聊天复用连接，无需保留 CMD 窗口，也不依赖 Windows 登录触发。
- **Windows 后台守护**：异常退出后重试，校验并清理受管进程树，提供 `daemon status`、`daemon restart` 和 `daemon logs -f`。
- **多语言命令**：支持简体中文、繁体中文、日文、西班牙文入口，英文命令继续有效；`/语言 中文` 切换回复与帮助页，保持原有权限校验。
- **飞书整轮单卡**：补充已有 `card_mode = "rich"` 的配置说明，正常长度的一轮任务复用一张卡，正常完成后折叠工具区，正文保持可见。

此前更新的提交与细节见 [CHANGELOG.md](https://github.com/tangboys/cc-connect/blob/v1.5.3-tangboys.3/CHANGELOG.md)。

## 下载与升级

提供 Linux、macOS、Windows 的 amd64 / arm64 包和 `checksums.txt`。选择对应操作系统和架构，校验 SHA-256 后解压。
Windows x64 选择 `cc-connect-v1.5.3-tangboys.3-windows-amd64.zip`。

已有机器人先等待当前任务结束，执行 `cc-connect daemon stop`，用发布包中的程序替换原程序，再执行 `cc-connect --version` 核对版本。
保留现有 `config.toml`，执行 `cc-connect daemon start` 恢复连接。使用 Codex 插件时请保持桌面窗口打开。
首次配置与插件安装见包内 `INSTALL.md`。

Windows 包自带 UTF-8 包装程序，不需要安装 Go。在解压目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\windows-utf8-shell\install.ps1
cc-connect daemon restart
```

在目标项目下启用飞书富卡片：

```toml
[projects.display]
card_mode = "rich"
```

## 验证与已知限制

- 已通过本机 Windows 构建、UTF-8 安装与环境覆盖回归、中文标准输出/标准错误及退出码测试。
- 已在实际 Codex 只读沙箱验证中文路径、原生命令输出及失败退出码，用户已确认飞书新卡片中文正常；相关飞书富卡片与核心事件测试通过。
- 本版本以预发布方式提供。Windows 全量测试仍有原有跨平台用例失败及 CLI 测试超时；Linux/macOS 包的交叉编译不代表已完成这些系统的实际运行验收。
- UTF-8 包装程序需执行安装脚本启用；重新运行 `daemon install` 后应重新启用。旧卡片中的乱码无法恢复。
- 桌面与飞书仍使用独立执行会话；共享任务的输入、暂停同步尚未实现。空白 Codex 窗口尚未加载插件时，需要打开一个聊天触发连接。
